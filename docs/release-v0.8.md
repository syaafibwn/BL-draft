# Blue Lock Draft V0.8

**Release date:** 3 November 2026

## Battle Sim

- Added Battle Sim as a playable mode, accessible from the homepage and main navigation.
- Build teams from an Auction draft, a saved Team Builder squad, or randomly generated players.
- Configure names, colours, formations, starters, reserves and team strategy.
- Play timed text-based matches with tactical movement, possession, passing, dribbling, shooting, goals, saves and match incidents.
- Handle substitutions during stoppages and review match statistics, player ratings and the event archive.
- Save squads to the shared Team Builder, return to setup with the match squads, and start rematches.

## Interface polish

- Removed coloured top strips from Battle Sim initializer team cards.
- Aligned Battle Sim secondary page-header spacing with the other pages.
- Removed the Early Access badge from the homepage Battle Sim card.
